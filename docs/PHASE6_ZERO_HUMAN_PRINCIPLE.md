# Phase 6 zero-human production principle

Insight Desk must not depend on routine human labeling or review to operate.

Human annotation may exist as optional offline evaluation material, but it is not a prerequisite for Phase 6 runtime closure. Tooling and policy must instead decompose semantic judgment into deterministic evidence checks, narrow local helpers, bounded auxiliary models with frozen roles, and fail-safe uncertainty.

If a candidate requires a user to install software, label data, approve each item, or resolve normal runtime ambiguity, it fails the production acceptance criterion.
